How do therapists keep track of sliding scale fees?

Write down each sliding scale client's agreed fee, the date you set it and a date to review it. Log every session at the fee you actually charged, plus what was paid. That shows what each client owes and what your reduced fees add up to each month. Review each agreed fee on its date, and change it in writing if the client's situation has changed.

How to set it up

  1. Write a short sliding scale policy: your full fee, your lowest fee, how many reduced-fee spots you offer and how often you review them. Use the same policy for everyone.
  2. Record each client's agreed fee by ID code, with the date you agreed on it and a review date, for example six or twelve months out.
  3. Log each session at the fee you actually charged, not your full fee, so balances only show money the client really owes.
  4. Label sliding scale clients so you can see how many you carry and pick them out when you review.
  5. Compare charged and collected each month. If reduced-fee clients fall behind, you'll see it in their balances early.
  6. Review each agreed fee on its review date. Raise it, keep it or lower it, write down the new fee and date, and use it from the next session.

If a client isn't using insurance, federal Good Faith Estimate rules may apply. CMS says providers usually must give clients who aren't using insurance a good faith estimate of expected charges if they ask for one or schedule at least 3 business days ahead. If you take insurance, check your payer contracts before offering reduced fees to clients who use it.

Common follow-up questions

Should I ask clients for proof of income?

That's a practice policy decision. Some therapists ask for it and many let clients pick their own fee from a set range. Whichever you choose, write it down and use it the same way for everyone.

How often should I review sliding scale fees?

Pick a schedule, such as every six or twelve months, and put the review date next to each client's agreed fee so it doesn't get missed.

Does a sliding scale client still get a Good Faith Estimate?

If they aren't using insurance, the federal Good Faith Estimate rules may apply to them like any other self-pay client. See CMS's good faith estimate page for the current rules.

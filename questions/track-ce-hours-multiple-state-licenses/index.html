How do counselors track CE hours when they're licensed in more than one state?

Keep one row per license, each with its own expiry date, renewal cycle, total hours required and any required topics such as ethics. Log every course once, then mark which licenses it counts for. Each license only counts courses taken inside its own renewal period, so you can see what each board still needs and which renewal comes up first.

How to set it up

  1. List every license and certification separately. Two states, plus a national certification, means three rows. Each has its own number, expiry date and renewal cycle.
  2. Copy each board's rules into its row: total hours for the cycle and the hours required in specific topics, like ethics, supervision or suicide prevention. Put 0 where a board has no rule for a topic.
  3. Log each course once, with the date, provider, hours and topic. Don't copy the same course into separate logs for each state.
  4. Mark which licenses each course counts for. Many courses count for more than one board, but not always. Check each board's approval rules before you credit a course to it.
  5. Count only courses inside each license's current period. Renewal dates rarely line up across states, so a course can be inside one period and outside another.
  6. Save each certificate and note that you did. If one board audits you, you can pull the proof for that license quickly.
  7. Sort by the next renewal date so the license that's closest to due gets your attention first.

CE rules differ by state and license type: total hours, required topics, limits on home-study or online hours, carry-over, and which providers are approved. Always check the current rules on each board's website.

Common follow-up questions

Can one CE course count for licenses in two states?

Often, yes, if both boards accept that course or provider. Some boards only accept certain approvals or limit some kinds of hours, so check each board before you count it twice.

What happens to my hours after I renew one license?

They stay in your log as a record, but they stop counting toward that license's new period. The other licenses keep counting them until their own periods end.

Does a national certification like the NCC need its own row?

Yes. Treat it like another license with its own renewal date and hour requirements, so you can credit the same courses to it where they qualify.

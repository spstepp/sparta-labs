How do I track where my therapy clients come from?

Ask every new inquiry how they found you and write it on their row, by ID code, the same day. Use a short, fixed list of sources, like a directory listing, your website, a doctor, a colleague or a former client, so the counts add up. After a few months, compare how many inquiries each source sent with how many became active clients. That shows which listings are worth paying for and which referrers to thank.

How to set it up

  1. Ask on the first call or email, while it's easy. "How did you hear about me?" is enough.
  2. Use the same few source names every time. "Psychology Today" and "PT" would count as two different sources.
  3. Log every inquiry, not just the ones who book. Otherwise you can't tell a source that sends lots of poor fits from one that sends a few good ones.
  4. Keep the status on the same row (waitlist, intake, active or discharged), so you can see which sources turn into clients.
  5. Count by source every month or quarter. A filter or a COUNTIF on the source column is enough.
  6. Before you renew a paid directory listing, check how many clients it actually sent you in the last year.

Referral notes can still be protected information. Keep names and contact details in a secure system, and follow your licensing board's rules on confidentiality when you thank or follow up with a referrer.

Common follow-up questions

What if a client found me in more than one place?

Write down the one that made them reach out. Using the same rule every time matters more than being exact.

Should I track inquiries that never book?

Yes. Those rows show which sources send people who don't fit your practice, and that's as useful as knowing which ones do.

How long before the numbers mean anything?

A few months for most solo practices. With only a handful of new clients a month, one quarter is a rough guide at best.

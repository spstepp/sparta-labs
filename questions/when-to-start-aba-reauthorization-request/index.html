When should ABA providers start a reauthorization request?

Start from the authorization's end date and work backward. Find out how far ahead each payer will accept a reauthorization request and how long their reviews usually take, then add the time you need to do the reassessment and write the updated treatment plan. That gives you a start date for each client. Keep every authorization's end date in one list, flagged when it gets close, so none of them sneaks up on you.

How to plan it

  1. Ask each payer for its rules. How far before the end date they accept a request, what they want in it, and roughly how long review takes. Write it down per payer, since it varies.
  2. Work back from the end date. End date, minus the payer's review time, minus the time to reassess and write the report. That's when the work has to start, not when the request goes in.
  3. Book the reassessment early. Families and staff schedules fill up. Getting it on the calendar is usually the slowest part.
  4. Keep all end dates in one view, with a warning window (for example 60 days) and an urgent window (for example 30 days). Pick windows that fit your slowest payer.
  5. Check unit pace at the same time. If a client will run out of units before the end date, you may need to request more sooner, or adjust the schedule.
  6. Note when each request was sent and any reference number. If a decision is late, you'll want that record when you call.

Reauthorization lead times, required documents and review times come from each payer and plan. Check with your payer, and follow your organization's policies.

Common follow-up questions

What if the new authorization starts before the old one ends?

Enter the dates the payer actually approved. In our tracker a session that falls inside both date ranges counts toward both, so set the new start date to the day after the old one ends, or match what the payer approved.

Should I wait for the reassessment before submitting?

Usually the payer wants the updated assessment and treatment plan with the request, which is why the reassessment has to be scheduled well before the end date. Your payer's requirements decide this.

What happens if the authorization lapses?

Sessions outside an active authorization may not be paid. That's the main reason to keep the end dates in one place with a warning window.
